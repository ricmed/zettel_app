## Resumo

Criar `Dockerfile`, `docker-compose.yml` e `.dockerignore` para subir a web UI e rodar a CLI sem instalar nada no host além do Docker.

## Contrato / comportamento

- **`Dockerfile`**:
  - multi-stage, no padrão oficial do uv;
  - instala com `uv sync --frozen --no-dev --extra ${TORCH_EXTRA}` (`ARG TORCH_EXTRA=cpu`);
  - base Python 3.12 slim, usuário não-root;
  - o `CMD` é `uvicorn zettel.web:app --host 0.0.0.0 --port 5000`.
- **`docker-compose.yml`**:
  - lê os segredos do `.env` (`env_file`) e expõe a porta 5000;
  - monta `./data`, `./vault` e `./config` (só leitura);
  - um volume nomeado guarda o cache do HuggingFace, para que os modelos do Docling não sejam baixados de novo a cada container.
- A CLI roda com `docker compose run --rm zettel python -m zettel <comando>`.
