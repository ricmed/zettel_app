## Resumo

Criar `scripts/setup.ps1` (Windows) e `scripts/setup.sh` (Linux e macOS). Cada um leva um clone limpo até o `zettel doctor` com um único comando.

## Contrato / comportamento

Os scripts são idempotentes: rodar de novo não estraga nada.

1. Sem o uv instalado, o script mostra o comando oficial de instalação e para. Ele não baixa nem executa nada por conta própria.
2. A escolha do torch segue esta ordem:
   - `--cpu` ou `--cuda` forçam a variante;
   - sem flag, com `nvidia-smi` no sistema, usa `uv sync --extra cu126`;
   - sem flag e sem `nvidia-smi`, usa `--extra cpu`;
   - no macOS, roda sem extra.
3. Se o `.env` não existir, copia o `.env.example`. Se `SESSION_SECRET` estiver vazio, gera um valor com `secrets.token_urlsafe(32)`.
4. Roda `zettel init` e, em seguida, `zettel doctor`.

O uv baixa o Python 3.12 sozinho a partir do `.python-version`.

## Critérios de aceite

- [ ] Num worktree limpo, `scripts/setup.ps1` chega ao `doctor` sem intervenção.
- [ ] Rodar o script uma segunda vez não sobrescreve o `.env` nem o `SESSION_SECRET`.
