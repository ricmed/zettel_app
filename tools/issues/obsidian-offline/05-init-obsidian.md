## Resumo

O `zettel init`, e um novo `zettel obsidian setup` para vaults que já existem, deve deixar o vault pronto para uso no Obsidian: com o Templater instalado e configurado, os *folder templates* ligados e os templates gerados. Assim, criar ou recriar o vault nunca exige copiar templates à mão.

## Motivação

O usuário não quer reinstalar nem copiar templates toda vez que cria um vault. Um plugin da comunidade do Obsidian é feito só de arquivos, então o init pode escrevê-los:

- `.obsidian/plugins/templater-obsidian/{main.js,manifest.json,styles.css}`;
- `.obsidian/community-plugins.json` (`["templater-obsidian"]`);
- `.obsidian/plugins/templater-obsidian/data.json`, com as configurações descritas abaixo.

## Contrato / comportamento

- **Configuração do Templater** (`data.json`):
  - `templates_folder: 99_Templates`;
  - `user_scripts_folder: 99_Templates/scripts`;
  - `trigger_on_file_creation: true`;
  - `enable_folder_templates: true`;
  - `folder_templates`:
    - `10_Sources` → `SRC.md`;
    - `20_Literature` → `LIT - granular.md`;
    - `30_Permanent` → `ZTL.md`;
    - `40_MOCs` → `MOC.md`.
- **Plugin core.** O plugin core de Templates fica desligado para não competir com o Templater (`core-plugins.json`). As demais escolhas do usuário são preservadas.
- **Origem dos arquivos do plugin.**
  - A release fica fixada em `config.yaml` (`obsidian.templater_version` mais o `sha256` de cada arquivo).
  - Os arquivos são baixados uma única vez do release oficial para `data/cache/obsidian/` e verificados pelo hash.
  - Para recriar o vault, o cache é usado, sem rede.
  - Se não houver cache nem rede, o init escreve a configuração e os templates, mostra a instrução de instalação manual e **não falha**.
- **Licença.** Antes de escolher entre embutir os arquivos no repositório ou baixá-los, é preciso verificar a licença do Templater.
- **Mesclagem.** Um `.obsidian/` que já existe é mesclado chave a chave, nunca sobrescrito às cegas. `obsidian setup --force` regrava os templates.
- **Ponto de atenção.** Na primeira abertura, o Obsidian pede para confiar no vault e desligar o modo restrito. É decisão do usuário: o init só informa.
- **Atalho opcional.** A CLI do Obsidian (1.12+, `obsidian create ... template=...`) pode ser documentada como atalho, mas não é dependência, porque exige o app aberto.
